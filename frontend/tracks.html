Ablagen

▾

Ziehe eine Datei auf eine Ablage – oder klicke sie an, um eine Datei auszuwählen. Die hinterlegte Aufgabe läuft dann von selbst; das Ergebnis erscheint unter der Ablage.

Was beim Ablegen geschieht
  • Die Datei wird auf dem Server abgelegt und – soweit möglich – als Text gelesen (PDF auch per Texterkennung).
  • Die Aufgabe der Ablage läuft mit deinen Rechten. Sie kann nichts, was du nicht auch im Chat könntest.
  • Erzeugte Dateien erscheinen als Download unter dem Ergebnis. Sie gehören dir; niemand sonst kann sie laden.
  • Läufe warten in einer Schlange, wenn gerade andere arbeiten – du kannst die Seite verlassen.
Was du beachten musst
  • Der Inhalt einer zugesandten Datei ist Fremdtext. Steht darin eine „Anweisung", wird sie als Angriffsversuch behandelt und nicht befolgt – prüfe das Ergebnis trotzdem, bevor du es weitergibst.
  • Zahlen, Adressen und Kennungen aus Texterkennung (OCR) am Original nachprüfen.
